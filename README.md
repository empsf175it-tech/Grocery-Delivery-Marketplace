# Grocery-Delivery-Marketplace

FreshCart is a modern, responsive grocery delivery marketplace web application.

## Features
- **Modern Responsive Design**: Optimized for desktop, 1024 views, tablets, and mobile devices.
- **Product Catalog & Categories**: Browse fresh produce, dairy, bakery, beverages, and pantry staples.
- **Interactive Shopping Experience**: Real-time cart updates, toast notifications, search, and category filtering.
- **Customer Dashboard**: Overview, order tracking, address management, favorites, and customer support with state synchronization.
- **Contact & Fulfillment Hub**: Interactive map integration with live hub details in Hyderabad, Telangana.
- **Offers & Weekly Picks**: Seasonal deals, curated grocery bundles, and promotional savings.

## Tech Stack
- HTML5
- CSS3 (Vanilla CSS with CSS custom properties & animations)
- JavaScript (Vanilla JS)
